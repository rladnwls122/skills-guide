# 짝 없는 모듈의 lab 분리 — 구축과 훈련을 가른다

날짜: 2026-08-29
상태: 승인됨

## 왜 이 문서를 쓰나

`style.mdx` H 절이 lab 의 계약을 세 단계로 정했다 — 이행 → 복기 → 복구·진단.
명령을 그대로 쳐서 성공하는 경험은 역량을 만들지 않는다는 것이 근거다.

lab 32개를 감사했더니 PART-1~3(06~13)은 이행 절에 명령이 0줄로 완전히 지키고
있었고, **27~31 다섯 모듈은 그 계약이 아예 없었다.** 처음부터 끝까지 정답 코드를
펼쳐 보여 준다. 문서의 절반이 코드다.

| 모듈 | 정답 코드 | 명령·출력 | 산문 |
|---|---|---|---|
| 27 network-firewall | 316 | 71 | 143 |
| 28 cicd-pipeline | 311 | 82 | 129 |
| 29 gitops-rollouts | 171 | 153 | 178 |
| 30 stepfunctions-apigw | 244 | 88 | 142 |
| 31 macie-masking | 172 | 181 | 134 |

계약이 없는 이유가 있다. **이 다섯은 기준본과 타깃이 짝지어지지 않는다.** 참고
구현이 한 벌뿐이라 "무엇에서 무엇으로"가 성립하지 않는다.

## 범위

**27·28·29·30·31 다섯 모듈.**

32(3과제 ECS)는 뺀다. `문서 유형: how-to` 이고 PART-5~6 은 "훈련 절차·판정 기준"
이라는 다른 계약을 따른다. 그 계약은 이미 지키고 있다.

19·20 은 이행 절이 있고 기계 감사의 문턱을 조금 넘었을 뿐이다. 구조 결손이
아니므로 이 작업의 대상이 아니다.

## 결정

### 문서를 둘로 가른다

| 파일 | 유형 | sidebar | 담는 것 |
|---|---|---|---|
| `lab.mdx` | tutorial | 3 | 구축 — 지금 내용 유지 |
| `drill.mdx` | tutorial | 4 | 훈련 — 계약 세 단계 |

절마다 정답 코드를 접는 방식(최소 변경)을 택하지 않았다. 스스로 답할 질문
목록이 없으면 접어 둔 것을 바로 펼치게 되어 따라 치기가 그대로 남는다.

### `막혔을 때` 가 양쪽에 있는 것은 중복이 아니다

| | lab 의 `막혔을 때` | drill 의 진단 절 |
|---|---|---|
| 상황 | 만들다 막혔다 | 만든 것을 일부러 고장 냈다 |
| 주는 것 | 증상별 원인 | 증상만. 볼 곳 순서는 학습자가 정한다 |

### `drill.mdx` 골격

```
0. 기준본 세우기      lab 결과를 한 덩어리로 재현 + 섰는지 확인하는 명령 한 줄
1. 변동 과제지        요구 산문 + 기준본과의 차이 표. 정답 코드 없음
2. 이행 (타이머 N분)  스스로 답할 질문 목록. 절차 지시 금지
3. 통과 기준          옛 이름 잔존 grep · validate/plan · 확인 명령
4. 복기               <details> 정답 + 놓친 곳 분류표
5. 고장 주입 진단     증상 2건. 증상 -> 볼 곳 순서 -> <details> 원인
6. 정리
```

0절이 필요한 이유는 `lab.mdx` 가 `terraform destroy` 로 끝나기 때문이다. drill 은
빈 계정에서 시작한다.

### 변동 축은 자체 제작한다

짝이 없으므로 변동을 직접 만든다. 19·20 이 이미 쓰는 방식이고 `links.mdx` 에
`:badge[자체 제작]` 로 표시돼 있다.

| 모듈 | 기준본 | 이행 타깃 |
|---|---|---|
| 27 | `http.host` 로 HTTP 만 차단 | TLS SNI 까지 + `drop` -> `reject` |
| 28 | A 경로 CodeBuild·CodePipeline | B 경로 Actions + OIDC 로 교체, A 는 지운다 |
| 29 | Blue/Green | Canary + 단계별 분석으로 전략 교체 |
| 30 | 재고 차감 한 갈래 | 재고 부족 분기(Choice) + 403 추가 |
| 31 | 마스킹 6종 | UUID 추가 + 경계 문제 · 접두사 변경 |

**기전은 실재하는 것만 쓴다.** 다만 이것은 출제 예측이 아니라 훈련용으로 만든
축이며, 각 문서에 그렇게 적는다.

28 이 특히 값싸다 — 두 경로가 이미 문서 안에 있어 지우는 판단까지 훈련된다.

### 고장은 지어내지 않는다

모듈당 2건을 그 모듈 `theory.mdx` 의 `:::danger` 블록에서 가져온다. 이미 실측된
함정이라 증상과 원인이 문서 안에서 검증돼 있다.

| 모듈 | 고장 |
|---|---|
| 27 | 라우팅이 방화벽을 비켜 간다 · SNI 규칙 누락 |
| 28 | `privileged_mode` 꺼짐 · 아티팩트 이름 불일치 |
| 29 | IRSA 신뢰 정책 끊김 · ARN 접미사 누락 |
| 30 | `.$` 누락으로 경로가 글자로 저장 · 메서드 응답 미등록 |
| 31 | 같은 버킷 무한루프 · 경계 없는 정규식 |
