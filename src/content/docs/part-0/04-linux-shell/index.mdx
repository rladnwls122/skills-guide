> 문서 유형: 개요

3과제는 요구사항을 구현하는 과제가 아니다. **당일 배부되는 프로그램을 분석해 띄우고 운영하는 과제**다. 그 프로그램은 리눅스용 바이너리로 오고, 환경 변수를 읽어 데이터베이스에 붙고, 로그를 표준 출력으로 뱉는다.

이 문장에 나오는 말 — 바이너리, 실행 권한, 환경 변수, 표준 출력 — 을 전부 손으로 다뤄 본 사람과 아닌 사람의 차이가 그날 시간으로 나온다.

## 왜 이 모듈이 중요한가

- 배부된 파일은 대개 **실행 권한이 없는 상태**로 온다. 권한을 못 주면 시작조차 못 한다.
- 앱은 설정을 **환경 변수**로 받는다. 어떤 이름으로 받는지는 그날 확인해야 한다.
- 로그가 표준 출력으로 나온다는 것은 **파일로 안 남는다**는 뜻이다. 어디로 흘려보낼지 정해야 한다.
- 컨테이너 이미지를 만들 때 하는 일 대부분이 결국 리눅스 명령이다.

## 목표

- [ ] 파일 권한을 읽고 실행 권한을 준다
- [ ] 환경 변수를 설정해 프로그램에 넘기고, 프로세스마다 따로라는 것을 확인한다
- [ ] 표준 출력과 표준 오류를 구분해 각각 다른 곳으로 보낸다
- [ ] 파이프라인으로 로그를 걸러 필요한 줄만 뽑는다
- [ ] 서비스로 등록해 자동 재시작하게 만든다
- [ ] 로그를 어디서 보는지 안다
