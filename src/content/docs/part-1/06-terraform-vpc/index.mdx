## 학습 목표

- [ ] provider / variable / tfvars / output / data source / locals / `for_each` / `aws_iam_policy_document` 문법을 남의 코드 없이 직접 쓸 수 있다
- [ ] set-02 기준 VPC(172.16.0.0/16, pub/priv 서브넷 4, IGW, NAT 2, RTB 3)를 백지에서 작성할 수 있다
- [ ] 과제지에 따라 바뀌는 파일(`variables.tf`·`tfvars`·리소스 tf·`outputs.tf`)과 그대로 재사용할 부트스트랩(`versions.tf`·`data.tf`)을 구분한다
- [ ] RTB↔서브넷 매핑(공용 public RTB 1개 + AZ별 private RTB 2개)이 채점 대상임을 이해하고 정확히 연결할 수 있다
- [ ] `terraform output -json` + jq 로 값을 뽑아 `.env` 파일로 영속화할 수 있다
- [ ] 비번호(`player_number`) 등 바뀌기 쉬운 값을 변수화하는 습관을 만든다

## 소요 시간

- 약 4~6시간 (이론 1.5h + 실습 3h + 정답 diff 1h)

## 과금 리소스와 destroy 방침

| 리소스 | 과금 | 방침 |
|---|---|---|
| NAT Gateway ×2 | **시간당 + 데이터 처리량 과금** (가장 큼) | **당일 실습 종료 즉시 `terraform destroy`** |
| EIP ×2 | NAT 에 붙어있는 동안 무료, destroy 시 함께 해제 | destroy 로 자동 정리 |
| VPC/서브넷/IGW/RTB | 무료 | destroy 로 함께 정리 |

:::caution[과금 주의]
**절대 NAT 를 밤새 켜두지 않는다.** 실습을 이어서 하려면 다음 날 다시 apply 한다 (state 가 로컬이므로 apply 만 다시 하면 됨).
:::

## 선행 지식

- 블록 타입·라벨 2개·인자로 이뤄진 HCL 블록 구조와 참조 주소 5종 — [hcl-basics](/start/hcl-basics/)
- 참조 관계가 실행 순서를 만든다. 순환 참조면 apply 가 거부된다 — [hcl-basics](/start/hcl-basics/)
- `for_each` 가 list 를 거부하고 `toset()` 을 요구하는 이유 — [hcl-basics](/start/hcl-basics/)
- 서브넷이 퍼블릭인지 결정하는 것은 이름이 아니라 **연결된 RTB** — [vpc-basics](/start/vpc-basics/)
- 프라이빗 인스턴스의 아웃바운드 경로: 프라이빗 RTB → NAT GW → 퍼블릭 RTB → IGW — [vpc-basics](/start/vpc-basics/)
- SG는 스테이트풀, NACL은 스테이트리스 — [vpc-basics](/start/vpc-basics/)
- `--query`(JMESPath)와 `jq`로 출력에서 값만 뽑는 법 — [awscli-basics](/start/awscli-basics/)

막히는 항목이 있으면 그 링크를 먼저 읽는다. 아니면 바로 다음 파일로 간다.

## 공식 문서

전부 읽지 않는다. 각 문서에서 **읽을 자리**만 적었다.

**모듈에 들어가기 전에 읽는다**

- [Terraform 언어 레퍼런스](https://developer.hashicorp.com/terraform/language) · 블록 종류와 표현식을 설명하는 앞부분. `resource`·`variable`·`output` 이 각각 무엇을 하는지가 여기서 정해진다
- [Amazon VPC 사용 설명서](https://docs.aws.amazon.com/vpc/latest/userguide/) · 라우팅 테이블과 NAT 게이트웨이를 다루는 부분. 서브넷을 공용과 사설로 가르는 것이 라우팅이라는 사실이 이 모듈의 출발점이다

**실습 중 대조한다**

- [AWS provider 리소스 색인](https://registry.terraform.io/providers/hashicorp/aws/latest/docs) · `aws_vpc`·`aws_subnet`·`aws_route_table` 세 페이지의 인자 목록과 Attribute Reference. 반환 속성 이름은 외우지 않고 여기서 찾는다
- [`for_each` 메타 인자](https://developer.hashicorp.com/terraform/language/meta-arguments/for_each) · map 과 set 을 받는 부분, 그리고 `each.key`·`each.value` 참조. 서브넷을 반복으로 만들 때 연다
- [Terraform CLI 명령](https://developer.hashicorp.com/terraform/cli/commands) · `plan`·`apply`·`output` 세 항목과 `-target` 옵션. 일부만 적용할 때 연다
