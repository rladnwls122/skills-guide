> 문서 유형: 개요

2과제 set-08 task-2 module-2(Simplify Service Networking with VPC Lattice)를 다룬다. **리전은 도쿄 ap-northeast-1** — 다른 2과제 모듈과 리전이 다르므로 착각하면 이 모듈 배점(7.5점) 전체를 잃는다. 정답 구현은 `skills-2026`의 브랜치 `set-08/task-2`, `set-08/task-2/module-2-lattice`에 있다 — 이 문서로 먼저 손으로 만든 뒤 대조한다.

## 학습 목표

채점 스크립트(`asgmt2_module2_check.sh`)의 5항목(각 1.5점, 총 7.5점) 그대로다.

- [ ] [2-1] Client VPC(`10.61.0.0/16`)·Service VPC(`10.62.0.0/16`)를 피어링·Transit Gateway 없이 만들 수 있다
- [ ] [2-2] Client/Service EC2에 지급 앱(`client_app.py`·`service_app.py`)을 배치하고, Client EC2에서 `curl /health`가 200을 반환하게 할 수 있다
- [ ] [2-3] Service Network·Service·VPC Association·Service Association을 전부 ACTIVE 상태로 만들 수 있다
- [ ] [2-4] Target Group(Type `Instance`, HTTP/8080, health check `/health`)·Target 등록·Listener(HTTP/80 → TG Forward)를 구성하고, Service EC2 보안 그룹 인바운드를 심사위원이 JSON 원문으로 확인할 수 있는 상태로 만들 수 있다
- [ ] [2-5] E2E로 `curl /v1/client/orders?id=1001`이 `order_id=1001, via=vpc-lattice`를 반환하게 할 수 있다

## 소요 시간 / 일차

- **Day 12** (모듈 11~13 묶음). 약 3~4시간 (이론 1~1.5h + 실습 2~2.5h).

## 과금 리소스와 destroy 방침

| 리소스 | 과금 | 방침 |
|---|---|---|
| VPC Lattice Service Network (VPC Association) | **시간당 과금** | 실습 종료 즉시 삭제 |
| VPC Lattice Service (Service Association 포함) | **시간당 + 처리량(GB) 과금** | 실습 종료 즉시 삭제 |
| EC2 t3.micro ×2 | 시간당 과금 (소액) | 실습 종료 즉시 종료(terminate) |
| VPC·서브넷·IGW·보안 그룹 | 무료 | destroy로 정리 |
| NAT Gateway | 사용 안 함 | Service EC2는 프라이빗 서브넷 + Lattice 경로만 쓰므로 애초에 불필요 |

:::caution[과금 주의]
VPC Lattice는 **Service Network VPC Association 시간당 + Service 처리량(GB)** 과금이 겹친다. 리소스 개수가 적어 보여도 켜둔 시간만큼 계속 청구된다 — 실습 종료 즉시 [lab](/part-4/12-vpc-lattice/lab/) 말미의 정리 절차를 순서대로 실행한다.
:::

## 선행 지식

- VPC 피어링·Transit Gateway의 한계(전이성 없음·CIDR 겹치면 불가) — [vpc-basics](/start/vpc-basics/)
- SG는 인스턴스 단위 스테이트풀 방화벽이고 소스로 다른 SG·프리픽스 리스트를 지정할 수 있다는 감각 — [vpc-basics](/start/vpc-basics/)
- L3 라우팅과 L7 서비스 네트워킹이 무엇을 보고 목적지를 정하는지 — [vpc-basics](/start/vpc-basics/)
- AWS 관리형 프리픽스 리스트 조회와 `--ip-permissions` 로 SG 규칙에 넣는 문법 — [vpc-basics](/start/vpc-basics/)
- `--query`로 CLI 응답에서 ID·상태 값을 뽑는 패턴 — [awscli-basics](/start/awscli-basics/)
- heredoc·`curl.exe`·PowerShell 따옴표 규칙 — [shell-basics](/start/shell-basics/)

막히는 항목이 있으면 그 링크를 먼저 읽는다. 아니면 바로 다음 파일로 간다.
