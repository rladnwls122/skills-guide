> 문서 유형: 개요

2과제 CDN Function 모듈(set-07 task-2 모듈 2, 리전 **us-east-1** — task.md·mark.md 양쪽에서 확인)이다. 이 사이트에 지금까지 이 주제가 없었다. S3(OAC) + CloudFront KeyValueStore(KVS) + CloudFront Functions(`cloudfront-js-2.0`)로 쿠키 기반 A/B 테스팅을 구성하고, 채점 스크립트(`mark2.sh`) 6항목을 통과시키는 것이 목표다.

## 학습 목표

- [ ] `mark2.sh` 2-1-A — S3 버킷(`skillsphone-landing-ab-<ACCOUNT_ID>`)의 오브젝트 2개(`version-a/index.html`, `version-b/index.html`), 퍼블릭 액세스 차단 4종, OAC 버킷 정책(Service principal + `AWS:SourceArn` 조건)을 통과시킬 수 있다
- [ ] `mark2.sh` 2-2-A — KVS 키 3개(`weight`/`version_a`/`version_b`)가 정확히 일치하고, 두 CloudFront Functions가 `LIVE` 스테이지에서 `DEPLOYED` 상태 · `cloudfront-js-2.0` 런타임으로 조회되며, viewer-request 함수가 그 KVS와 연결돼 있음을 통과시킬 수 있다
- [ ] `mark2.sh` 2-3-A — 캐시 정책(쿠키 화이트리스트 `x-sp-ab`, TTL 0/300/3600)과 distribution(OAC 연결, `redirect-to-https`, viewer-request/response 함수 2개 연결)을 통과시킬 수 있다
- [ ] `mark2.sh` 2-4-A — 쿠키를 강제로 보내면 그 버전 본문만 오고 `Set-Cookie`가 없으며, HTTP 요청이 HTTPS로 30x 리다이렉트됨을 통과시킬 수 있다
- [ ] `mark2.sh` 2-5-A — 쿠키 없는 첫 방문이 무작위 버전을 배정받아 `Set-Cookie ...; Path=/; Max-Age=86400`을 받고, 같은 쿠키로 재방문하면 같은 버전 + `Set-Cookie` 없음을 통과시킬 수 있다
- [ ] `mark2.sh` 2-6-A — 코드 재배포 없이 KVS의 `weight` 값만 바꿔도 `test-function` 결과 URI가 즉시 바뀜을 통과시킬 수 있다

## 과금 리소스와 destroy 방침

| 리소스 | 과금 | 방침 |
|---|---|---|
| S3 (버킷 1개 + 정적 객체 2개) | 저장/요청 소액 | destroy로 정리 |
| CloudFront Distribution | 요청·전송량 과금(실습 규모에서 무시 가능) | 실습 종료 시 destroy — disable→삭제 전파로 몇 분 소요 |
| CloudFront Functions ×2 | 100만 호출당 소액 | destroy로 정리 |
| CloudFront KeyValueStore (키 3개) | 저장·읽기 소액 | destroy로 정리 |

:::caution[과금 주의]
NAT·EKS 처럼 시간당 과금이 큰 리소스는 없다. 그래도 distribution을 켜 둔 채 방치하면 요청·전송량 과금이 계속 붙는다. destroy 자체도 disable→삭제 전파로 몇 분 걸린다 — 실습 종료 즉시 destroy 한다.
:::
