> 문서 유형: 개요

2과제 후보 **set-08 task-2 module-1**을 다룬다. Amazon DocumentDB(MongoDB 호환)에 소매 주문·상품·세션 데이터를 저장한다. 지급된 Python 클라이언트(`docdb_client.py`)로 조회 API 를 서비스한다. 본 모듈은 **ap-northeast-2(서울)** 리전에 리소스를 생성한다 — 2과제는 모듈마다 리전이 다르고, 틀리면 그 모듈은 0점이다.

정답 구현은 2026-08-01에 들어왔다 — `skills-2026` `main` 의 `set-08/task-2/module-1-nosql`(Terraform)과 `mark/mark2-1.sh` 에 있다. 같은 날 배포된 정정본이 항목별 판정 기준의 정본이다.

## 학습 목표

- [ ] `aws docdb describe-db-clusters`·`describe-db-instances`·`aws kms describe-key` 조회에서 클러스터·인스턴스가 `available`, 스토리지 암호화 `Enabled`, 백업보존 1일 이상, KMS 키 `Enabled`를 통과시킬 수 있다
- [ ] Secret `skills-nosql-docdb-secret`에 `username`·`password`·`host` 3키를 채우고, `skills-nosql-client-ec2` 이름의 EC2를 `running` + Public IP 상태로 만들 수 있다
- [ ] `curl http://<IP>:8080/health`와 `/v1/admin/summary`가 HTTP 200과 `orders 8 / products 6 / sessions 3` + BSON Date 적재 상태를 반환하게 만들 수 있다
- [ ] `/v1/admin/indexes` 채점을 통과시킬 수 있다 — unique·복합·정렬 방향·TTL(`expireAfterSeconds: 0`)까지 전부 직접 만들어서
- [ ] `/v1/orders/O-1001`·`/v1/customers/C001/orders`·`/v1/orders/pending`·`/v1/products/low-stock?warehouseId=W-A` 4종 조회를 모두 HTTP 200 + 기대 데이터로 통과시킬 수 있다

## 소요 시간

-  — 모듈 18~23(DocumentDB · VPC Lattice · CDN Function)을 하루에 묶는다. 셋을 합치면 10~12h 라 하루를 넘길 수 있다 — 밀리면 모의 대회·드릴에 쓰려던 여유 시간에서 당겨 쓴다.
- 약 4~5시간 (이론 1~1.5h + 실습 3~3.5h). DocumentDB 자체 개념은 얕지만 VPC·IAM·EC2 준비 절차가 길어 실습 비중이 크다.

## 과금 리소스와 destroy 방침

| 리소스 | 과금 | 방침 |
|---|---|---|
| DocumentDB 인스턴스 db.t3.medium ×1 | 시간당 과금 (이 모듈에서 가장 큼) | 실습 종료 즉시 인스턴스→클러스터 순서로 삭제 |
| DocumentDB 클러스터 스토리지·I/O | 사용량 기반 | 인스턴스·클러스터 삭제로 함께 정리 |
| EC2 (Client) ×1 | 시간당 과금 (소액) | 실습 종료 즉시 종료 |
| Secrets Manager 시크릿 | 월정액 소액 | 기본 삭제는 복구 대기 기간이 있다 — 강제 삭제 옵션으로 즉시 정리 |
| KMS 고객관리형 키(`alias/skills-nosql-docdb`) | 월정액 소액 | alias만 지워서는 과금이 멈추지 않는다 — 키 자체를 삭제 예약 |

:::caution[과금 주의]
DocumentDB 인스턴스는 RDS와 달리 **중지(stop) 기능이 없다.** 삭제만이 과금을 멈춘다 — 실습을 하루 안에 못 끝내도 인스턴스는 그날 지운다.
:::

## 선행 지식

- VPC·서브넷·보안 그룹으로 "공개 앱 계층 + 비공개 데이터 계층"을 가르는 법 — [vpc-basics](/start/vpc-basics/)
- 인스턴스 프로파일과 최소 권한 정책 — EC2가 Secrets Manager를 읽으려면 역할이 필요하다 — [iam-basics](/start/iam-basics/)
- CMK와 별칭(alias)의 관계 — [kms-basics](/start/kms-basics/)
- `aws ... --query`로 리소스 상태를 조회하는 법 — [awscli-basics](/start/awscli-basics/)

막히는 항목이 있으면 그 링크를 먼저 읽는다. 아니면 바로 다음 파일로 간다.

## 공식 문서

전부 읽지 않는다. 각 문서에서 **읽을 자리**만 적었다.

**모듈에 들어가기 전에 읽는다**

- [Amazon DocumentDB 란 무엇인가](https://docs.aws.amazon.com/documentdb/latest/developerguide/what-is.html) · 클러스터와 인스턴스의 관계를 설명하는 부분. 저장 계층이 인스턴스와 분리돼 있다는 구조가 전제다
- [Amazon DocumentDB 보안](https://docs.aws.amazon.com/documentdb/latest/developerguide/security.html) · TLS 항목. 기본이 TLS 필수라 인증서 없이 붙으면 연결부터 실패한다

**실습 중 대조한다**

- [Amazon DocumentDB 동작 방식](https://docs.aws.amazon.com/documentdb/latest/developerguide/how-it-works.html) · 인덱스와 TTL 을 다루는 부분. 만료 삭제를 요구받을 때 연다
- [AWS Secrets Manager 사용 설명서](https://docs.aws.amazon.com/secretsmanager/latest/userguide/intro.html) · 비밀 저장과 조회 절차. 접속 정보를 코드에 박지 않기 위해 연다
- [PyMongo 문서](https://pymongo.readthedocs.io/en/stable/) · 연결 문자열과 TLS 옵션 항목. 실습 클라이언트가 쓰는 드라이버다
