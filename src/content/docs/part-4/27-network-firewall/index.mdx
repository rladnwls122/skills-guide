> 문서 유형: 개요

[2025 실기출](/reference/past-exams/)에서 **1과제와 2과제에 모두** 나온 축이다. 1과제에서는 Hub VPC 의 방화벽 서브넷에 두고 App VPC 의 외부 요청을 검사했다. 2과제 Secure networking 모듈에서는 Egress VPC 에 두고 3단 방어를 요구했다.

:::caution[사이트에 없던 축이다]
2024 년에는 나오지 않았고 2025 년에 두 과제에서 동시에 나왔다. 처음 만나면 개념 자체가 낯설다 — 보안 그룹이나 네트워크 ACL 과 무엇이 다른지부터 잡고 시작한다.
:::

:::tip[이 모듈은 문서가 넷이다]
개념은 [이론](/part-4/27-network-firewall/theory/), 구축은 [실습](/part-4/27-network-firewall/lab/), 그리고 **[드릴](/part-4/27-network-firewall/drill/)** 이 이행·복기·진단을 맡는다(약 25분). 실습을 마친 뒤에 연다.
:::

## 학습 목표

- [ ] 보안 그룹·네트워크 ACL·Network Firewall 셋의 검사 위치와 능력 차이를 설명할 수 있다
- [ ] 방화벽 전용 서브넷이 왜 따로 필요한지 설명할 수 있다
- [ ] 트래픽이 방화벽 엔드포인트를 거치도록 라우팅 테이블 네 개를 배치할 수 있다
- [ ] Stateless 규칙 그룹과 Stateful 규칙 그룹이 각각 무엇을 볼 수 있는지 구분한다
- [ ] Suricata 규칙 한 줄을 읽고 쓸 수 있다
- [ ] 도메인 이름으로 차단하는 규칙과 IP 로 차단하는 규칙의 한계를 안다
- [ ] FLOW 와 ALERT 로그 유형의 차이를 알고 요구된 것만 켤 수 있다
- [ ] 차단이 실제로 되는지 파드에서 확인할 수 있다
- [ ] 차단했는데 통하거나, 통해야 하는데 막힐 때 원인을 좁힐 수 있다

## 소요 시간

약 5~6시간 (이론 2h + 실습 3~4h)

## 과금 리소스와 destroy 방침

| 리소스 | 과금 | 방침 |
|---|---|---|
| **Network Firewall 엔드포인트** | **시간당 과금 + 처리량당 과금.** 이 모듈에서 가장 비싸다 | **실습 종료 즉시 destroy** |
| NAT Gateway | 시간당 과금 | 실습 종료 즉시 destroy |
| VPC·서브넷·라우팅 테이블 | 무료 | destroy 로 정리 |
| CloudWatch Logs | 저장량당 소액 | 로그 그룹까지 destroy |
| 테스트용 EC2 또는 파드 | 시간당 소액 | 확인 끝나면 즉시 삭제 |

:::danger[방화벽 엔드포인트를 켜 둔 채 자지 않는다]
Network Firewall 은 가용 영역마다 엔드포인트를 하나씩 만들고 **각각 시간당 과금**한다. 고가용성 요구로 두 곳에 두면 두 배다. 실습이 끝나면 반드시 `terraform destroy` 한다.
:::
