> 문서 유형: 개요

타이머 4시간, **대회 조건 그대로**(자기 런북·저장소·AWS 공식 문서 허용, **AI·검색 금지**) set-02 1과제를 처음부터 끝까지 돈다. terraform → docker/ECR → eksctl → k8s/helm → 검증 시드 → mark.sh 셀프 채점 순이다.

여기에 **문서에 없는 변형 3건**을 주입해 문서 밖 대응력까지 측정한다.

## 목표

- [ ] 4시간 내 완주, mark.sh 자동 채점 90% 이상 (런북 기반, AI 없이)
- [ ] 봉인된 변형 3건(문서에 없는 신규 요구)을 콘솔·manifest·tf 혼합으로 해결
- [ ] 착수 순서를 [timings](/reference/timings/)대로 몸이 기억함 (eksctl 20분 먼저 던지고 docker 병렬)
- [ ] 채점 직전 리셋 체크리스트를 빠짐없이 수행
- [ ] 아키텍처 백지 도식(화살표별 인증 방식 주석 포함) 재현
- [ ] 오답 노트 작성 + [troubleshooting](/reference/troubleshooting/) 반영

## 소요 / 일차

- 고정 일차 없음 — PART-2 완주(D8)를 마친 뒤부터 가능하고, 늦어도 3과제(D13~14) 전에 한 번은 친다. 4시간(본 시험) + 1~2시간(채점·회고·3과제 대비)

## 과금 / destroy

:::caution[커리큘럼에서 과금이 가장 큰 날]
풀스택 4시간+ 기동 — EKS·NAT GW·ALB·CloudFront 동시 과금.

회고까지 끝나면 즉시 destroy 한다.

1. k8s 리소스(LBC ALB 포함) 삭제
2. `eksctl delete cluster`
3. `terraform destroy`
4. CloudFront disable·삭제 확인
5. 콘솔에서 잔존 리소스 육안 확인
:::
