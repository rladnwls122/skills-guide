## 1. 계정과 신원

학습용 AWS 계정을 준비하고, **root 계정은 상시 사용하지 않는다.** root 로 apply 하면 set-03 유형의 root-less KMS 키 정책에서 이후 KMS 사용이 전부 거부된다(모듈 08에서 체험). 대신 IAM 사용자를 하나 만들어 그 신원만 쓴다.

<Steps>

1. **IAM 사용자 생성** — 콘솔 → IAM → 사용자 → 사용자 생성 → 이름(예: `skills`) → 권한 옵션에서 **직접 정책 연결** → `AdministratorAccess` 선택 → 생성.

2. **액세스 키 발급** — 만든 사용자 → 보안 자격 증명 탭 → 액세스 키 만들기 → 사용 사례 **CLI** 선택 → 생성.

   :::danger[시크릿 키는 이 화면에서만 보인다]
   화면을 벗어나면 다시 볼 수 없다. 지금 복사하거나 `.csv` 를 내려받는다. 잃어버리면 키를 새로 만들어야 한다. **이 두 값은 채팅·문서·저장소에 붙여넣지 않는다** — 유출되면 남이 내 계정으로 리소스를 만든다.
   :::

3. **CLI 에 등록** — `aws configure` 를 실행하면 네 가지를 묻는다.

   ```
   AWS Access Key ID     : 방금 받은 액세스 키 ID (AKIA... 로 시작)
   AWS Secret Access Key : 방금 받은 시크릿 키
   Default region name   : ap-northeast-2
   Default output format : json
   ```

4. **신원 확인** — 이 명령이 계정 ID 와 사용자 ARN 을 내면 끝이다.

   ```bash
   aws sts get-caller-identity
   ```

   `Unable to locate credentials` 가 나오면 3번을 다시 하고, `InvalidClientTokenId` 면 키를 잘못 붙여넣은 것이다.

</Steps>

대회 핵심 원칙: **클러스터 생성자 = kubectl 신원 = 채점 신원**. 지금부터 하나의 신원만 쓴다.

## 2. 도구 설치 (본 PC)

일곱 가지를 깐다 — AWS CLI v2, Terraform, eksctl, kubectl, helm, git, jq. 아래 블록을 그대로 실행한다.

<Tabs syncKey="shell">
  <TabItem label="PowerShell">
  ```powershell
  # PowerShell 7 부터 깐다 — 이 가이드의 모든 명령이 7 기준이다
  winget install --id Microsoft.PowerShell -e
  # 설치 후 "PowerShell 7" 창을 새로 열고 이어서 실행한다

  winget install --id Amazon.AWSCLI -e
  winget install --id Hashicorp.Terraform -e
  winget install --id Weaveworks.eksctl -e
  winget install --id Kubernetes.kubectl -e
  winget install --id Helm.Helm -e
  winget install --id Git.Git -e
  winget install --id jqlang.jq -e
  ```

  :::danger[Windows PowerShell 5.1 을 쓰지 않는다]
  파란 아이콘의 "Windows PowerShell" 이 5.1 이다. 기본 인코딩이 CP949 라 terraform·jq 출력이 깨지고, `&&` 연산자도 없다. 검은 아이콘의 **"PowerShell 7"** 을 쓴다 — `$PSVersionTable` 의 `PSVersion` 이 `7.x` 여야 한다.
  :::
  </TabItem>
  <TabItem label="Bash (Linux/CloudShell)">
  ```bash
  # CloudShell 에는 aws·git·jq·kubectl 이 이미 있다. 없는 것만 깔면 된다.

  # AWS CLI v2
  curl -fsSL "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o awscliv2.zip
  unzip -q awscliv2.zip && sudo ./aws/install --update

  # Terraform (HashiCorp APT 저장소 — Ubuntu/Debian)
  wget -qO- https://apt.releases.hashicorp.com/gpg | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp.gpg
  echo "deb [signed-by=/usr/share/keyrings/hashicorp.gpg] https://apt.releases.hashicorp.com $(lsb_release -cs) main" \
    | sudo tee /etc/apt/sources.list.d/hashicorp.list
  sudo apt update && sudo apt install -y terraform

  # eksctl
  curl -fsSL "https://github.com/eksctl-io/eksctl/releases/latest/download/eksctl_Linux_amd64.tar.gz" \
    | tar xz -C /tmp && sudo mv /tmp/eksctl /usr/local/bin/

  # kubectl
  curl -fsSLO "https://dl.k8s.io/release/$(curl -fsSL https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
  sudo install -m 755 kubectl /usr/local/bin/kubectl

  # helm
  curl -fsSL https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash

  # git, jq
  sudo apt install -y git jq
  ```

  :::note[배포판이 다르면]
  위는 Ubuntu/Debian 기준이다. Amazon Linux·RHEL 계열은 `apt` 를 `dnf` 로 바꾸고 Terraform 은 `sudo dnf config-manager --add-repo https://rpm.releases.hashicorp.com/AmazonLinux/hashicorp.repo` 를 먼저 실행한다.
  :::
  </TabItem>
</Tabs>

설치가 끝나면 **새 터미널을 열고** 일곱 줄을 확인한다. 하나라도 `command not found` 면 그 도구만 다시 깐다.

| 도구 | 확인 명령 | 기대 |
|---|---|---|
| AWS CLI v2 | `aws --version` | `aws-cli/2.x` |
| Terraform | `terraform version` | `v1.6` 이상 |
| eksctl | `eksctl version` | 버전 문자열 |
| kubectl | `kubectl version --client` | 클라이언트 버전 |
| helm | `helm version` | `v3.x` |
| git | `git --version` | 버전 문자열 |
| jq | `jq --version` | `jq-1.x` |

PowerShell 함정 미리 각인: `curl`은 Invoke-WebRequest 별칭 → 항상 `curl.exe`.
`$` 포함 문자열(Grafana 비번 등)은 작은따옴표.

## 3. 비용 가드레일

:::caution[시간당 과금 목록 암기]
**NAT GW, EKS 클러스터($0.1/h), MSK, ALB, EC2** — 켜 둔 시간이 그대로 청구된다.
:::

<Steps>

1. **AWS Budgets 알람 두 개 생성** (콘솔 5분, 또는 이어지는 CLI)

   월 알람만으로는 늦다. 월 $50 의 80% 는 $40 이라, NAT 를 하루 켜 둔 사고는 그 문턱에 닿기 전에 이미 일어난다. **일 단위 알람을 함께 건다** — 하루 $5 를 넘기면 그날 안에 메일이 온다.

   ```bash
   ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text)
   EMAIL='본인이메일@example.com'   # 본인 주소로 교체

   # (1) 월 $50 — 전체 상한
   aws budgets create-budget --account-id "$ACCOUNT_ID" \
     --budget '{"BudgetName":"skills-guide-monthly","BudgetLimit":{"Amount":"50","Unit":"USD"},"TimeUnit":"MONTHLY","BudgetType":"COST"}' \
     --notifications-with-subscribers "[{\"Notification\":{\"NotificationType\":\"ACTUAL\",\"ComparisonOperator\":\"GREATER_THAN\",\"Threshold\":80,\"ThresholdType\":\"PERCENTAGE\"},\"Subscribers\":[{\"SubscriptionType\":\"EMAIL\",\"Address\":\"$EMAIL\"}]}]"

   # (2) 일 $5 — destroy 를 잊은 날 그날 안에 알린다
   aws budgets create-budget --account-id "$ACCOUNT_ID" \
     --budget '{"BudgetName":"skills-guide-daily","BudgetLimit":{"Amount":"5","Unit":"USD"},"TimeUnit":"DAILY","BudgetType":"COST"}' \
     --notifications-with-subscribers "[{\"Notification\":{\"NotificationType\":\"ACTUAL\",\"ComparisonOperator\":\"GREATER_THAN\",\"Threshold\":100,\"ThresholdType\":\"PERCENTAGE\"},\"Subscribers\":[{\"SubscriptionType\":\"EMAIL\",\"Address\":\"$EMAIL\"}]}]"
   ```

   알람은 **사고를 막지 못하고 알리기만 한다.** 실제 방어선은 다음 두 항목이다.

2. **모듈 종료 = destroy**

   예외는 모듈 인덱스에 명시된 날만 (D4→D6 클러스터 유지).

3. **매일 학습 종료 시 잔존 리소스 일괄 점검**

   [잔존 리소스 점검](/reference/cleanup-check/) 블록을 실행 — 빈 출력이어야 그날이 끝난 것.

</Steps>

| 15 | Prometheus 가 메트릭을 어떻게 모으고 PodMonitor 가 무엇인지 안다 | [observability-basics](/start/observability-basics/)로 보충 |

9·10번은 **2과제 전용**이다. PART-4에 들어가기 전까지는 몰라도 진도가 막히지 않으므로, 자가진단 "아니오" 개수에는 넣되 보충은 PART-4 직전에 해도 된다.

Kubernetes·eksctl은 선수 지식 아님 — PART 1~2에서 배운다.

Terraform 은 다르다. **채점 대상이 아니다** — 과제지·채점지 어디에도 IaC 요구가 없고, 채점은 배포된 리소스 상태만 본다. 다만 수상 과제 정답지가 전부 Terraform 이고 당일 30% 변동을 30분에 반영하려면 읽고 고칠 줄 알아야 한다. 문법이 낯설면 [hcl-basics](/start/hcl-basics/) 로 먼저 보충한다.
